se ocijenilo djeluje li L2rx, mora ponovno učitati stvarni loši prijamnik i treba više događaja.

## 4. Nalaz: RX_EQA_CKP_OFFSET = 0 se ne upiše

R1 je zamišljen kao CAL0 + TX_SEL_PRE 0 + RX_EQA_CKP_OFFSET 0. Stvarno je primijenjeno samo CAL0 + TX_SEL_PRE 0 + DFE reset.
Readback polja RX_EQA_CKP_OFFSET (0x04[7:0]) i dalje je **1**:

- završni korak chain4 (`chain4.out`) ispisuje readback `board=m2|gs set ... TX_SEL_PRE=0 RX_EQA_CKP_OFFSET=1`;
- 2026-10-17 izravno na m2: `set RX_EQA_CKP_OFFSET=0` daje readback 1, `set RX_EQA_CKP_OFFSET=2` daje readback 1.
  Polje je vraćeno na 1, što je ionako stanje u kojem je bilo;
- `link_gate.py after_load()` ne provjerava readback ni izlazni kod `eyescan.py set`, pa je to prošlo nezapaženo u svim
  pokušajima s `--r1` (2,5G i 5G).

Zato sva mjerenja „R1" u chain4 vrijede za CKP_OFFSET = 1. Isto vrijedi i za `SOAK_R1_2G5_20261017.md`.
`RX_EQA_RESET` je W/C, pa je njegov readback 0 očekivan.
