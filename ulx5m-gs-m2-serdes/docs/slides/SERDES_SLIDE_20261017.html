3 · OPEN ISSUES

1

2.5G link gate passes 5 / 15

L3: 33 % [15 %, 58 %] (Wilson). Soak gate passed on attempt 9: 7 × "Q errors > 8", 1 × m2 RX_CDR_LOCKED = 0. No reset level (L1, L1b, L2tx, L2rx) shown to work.

2

RX_EQA_CKP_OFFSET is not written

set 0 → readback 1; set 2 → readback 1 (0x04[7:0], both boards). link_gate.py does not check readback, so all "R1" data is with OFFSET = 1.

3

M2 → GS is the weaker direction

50 vs 2 bit errors in 2.239e12 bits; worst 10 s window 5.6e-10. 5 of 7 gate "Q" failures were M2 → GS.

4

5G: no CDR lock, 9 / 9 attempts fail

All fail health/PEER before BER (no soak). gs RX_CDR_LOCKED mostly 0; 7–24 % invalid samples. PLL locked, CAP_FT_OF/UF = 0, RX_EQA_LOCKED 1: the 5G eye is not open.

5

VDD_SER not measured

VDD_SER / VDD_SER_PLL (R105/R106 = 2 Ω) not measured in this lab; supply can be neither confirmed nor ruled out. Next: TP10 / TP8 on both boards while the 5G bit runs.
