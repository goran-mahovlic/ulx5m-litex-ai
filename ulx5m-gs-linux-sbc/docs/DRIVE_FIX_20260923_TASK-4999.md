# IO_EB_A3 DRIVE fix — TASK-4999, 2026-09-23

## Root uzrok (identificiran)

`eth_refclk` (IO_EB_A3 = KSZ9031 XI pin 46) imao je `DRIVE=3` (3 mA).

**Simptomi DRIVE=3:**
- PHY interna referentna frekvencija ne starta → PLL ne locka → nema RXC
- MDIO čita `0x0000` za sve registre (PHY nema clock → ne obrađuje MDIO)
- MDIO sequencer šalje pakete ali PHY ne reagira → autoneg ostaje na default 1G
- Switch LED ostaje **zelena** (1G), cilj je **žuta** (100M)
- ARP INCOMPLETE — FPGA ne odgovara uopće

## Fix

`gateware/ulx5m_eth_platform.py`:

```python
# PRIJE (TASK-4963):
("eth_refclk", 0, Pins("IO_EB_A3"), Misc("SLEW=fast"), Misc("DRIVE=3")),

# POSLIJE (TASK-4999):
("eth_refclk", 0, Pins("IO_EB_A3"), Misc("SLEW=fast"), Misc("DRIVE=6")),
```

Razlog: svi ostali EB bank TX pinovi (eth_clocks_tx, tx_ctl, tx_data) koriste
`DRIVE=6`. Referentni clock je jedini koji je ostao na `DRIVE=3`.

**Commit:** `53e9ba9` na grani `mdio-100m-autoneg`
