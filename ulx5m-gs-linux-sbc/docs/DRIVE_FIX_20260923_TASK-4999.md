# IO_EB_A3 DRIVE fix — TASK-4999, 2026-09-23

## Root cause (identified)

`eth_refclk` (IO_EB_A3 = KSZ9031 XI pin 46) had `DRIVE=3` (3 mA).

**Symptoms of DRIVE=3:**
- The PHY internal reference frequency does not start → PLL does not lock → no RXC
- MDIO reads `0x0000` for all registers (PHY has no clock → does not process MDIO)
- The MDIO sequencer sends packets but the PHY does not react → autoneg stays at the default 1G
- Switch LED stays **green** (1G), the goal is **yellow** (100M)
- ARP INCOMPLETE — the FPGA does not answer at all

## Fix

`gateware/ulx5m_eth_platform.py`:

```python
# BEFORE (TASK-4963):
("eth_refclk", 0, Pins("IO_EB_A3"), Misc("SLEW=fast"), Misc("DRIVE=3")),

# AFTER (TASK-4999):
("eth_refclk", 0, Pins("IO_EB_A3"), Misc("SLEW=fast"), Misc("DRIVE=6")),
```

Reason: all other EB bank TX pins (eth_clocks_tx, tx_ctl, tx_data) use
`DRIVE=6`. The reference clock was the only one left at `DRIVE=3`.

**Commit:** `53e9ba9` on branch `mdio-100m-autoneg`
